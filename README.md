# Flame in Freefall

Эмулятор сферического диффузионного пламени в микрогравитации (1D по радиусу) и суррогатная ML-модель на его данных. Техническое задание: `FF_TZ.pdf`.

## Структура

- `emulator/reference/` — 1D сферическое ядро уровня 1 (Python + numba), основной предмет проекта
- `level0_2d/` — прежний 2D плоский решатель, используется как полигон для датчиков/конвейера, физически не развивается
- `formulas/` — безразмерные числа, излучение
- `configs/` — YAML-конфиги режимов
- `app/` — интерактивное демо на Streamlit
- `tests/` — верификационные и смоук-тесты

## Запуск

```
make build
make test
make app
```

Запуск одного прогона уровня 1 из командной строки с сохранением истории в HDF5:

```
python -m emulator.run configs/sflame_ch4.yaml --out data/run_0001.h5
```

## Статус

MVP уровня 1: сферическая геометрия, переменная плотность, стефановский поток, одна глобальная реакция Аррениуса, оптически тонкое излучение с константой поглощения. Упрощения относительно ТЗ (2-шаговая химия, 6 компонент, Cantera-калибровка, RADCAL, неявная диффузия) — предмет следующих этапов.
